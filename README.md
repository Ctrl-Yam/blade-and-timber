## Project Overview
Blade & Timber Co. is a modern, high-efficiency grooming and barber business based in Johannesburg. This project serves as a digital platform allowing clients to explore grooming packages, view branch locations and operating hours, and submit service enquiries or booking requests.

## Website Goals and Objectives
- **Modern Digital Presence:** Establish a clear online storefront for Blade & Timber Co.
- **Service Accessibility:** Provide a complete menu of barbering services, durations, and pricing.
- **Convenient Booking:** Enable customers to submit custom booking requests and general enquiries online.
- **Multi-Branch Visibility:** Display precise location, contact information, and operating hours for Rosebank and Braamfontein branches.

## Key Features and Functionality
- Semantic HTML5 structure across all pages for optimal accessibility and SEO.
- Multi-page navigation (Home, About, Services, Enquiry, Contact).
- Interactive service booking and enquiry form.
- Embedded location maps for physical branches.
- Fully hosted and deployed via GitHub Pages.

## Timeline and Milestones
- **Phase 1 (Part 1):** Research, HTML structural layout, semantic tagging, and GitHub deployment.
- **Phase 2 (Part 2):** CSS styling, responsive layout design, and UI enhancement.
- **Phase 3 (Part 3):** JavaScript functionality, form validation, and final deployment.

## Part 1 Details
Focuses strictly on building a robust, accessible HTML skeleton for all 5 core pages, setting up version control with Git/GitHub, and establishing the initial GitHub Pages deployment.
